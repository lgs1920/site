## Choose Output

Use the export type that matches the work:

| Need | Use |
| --- | --- |
| One composed image | Snapshot |
| Camera movement or timed scene | Video |
| Route documentation with metadata and maps | Journey report |

## Snapshot And Video

For a scene capture:

1. Prepare layers, journey visibility, POIs, widgets, and camera.
2. Check the capture area and aspect ratio.
3. Use the snapshot or video action.
4. Review the generated output before changing the scene.

Detailed flow: [Snapshots and video](/user-guide/workflows/snapshots-and-video/).

## Report

For a journey report:

1. Select the active journey.
2. Check title, description, dates, statistics, POIs, and track styling.
3. Generate the PDF or HTML ZIP report.
4. Open the exported file and review generated maps and tables.

Detailed flow: [Journey reports](/user-guide/workflows/journey-reports/).

## Final Checks

Before exporting anything:

1. Hide drawers and dialogs that should not be visible in the output.
2. Check that widgets are inside the capture area.
3. Check map layer contrast.
4. Run camera movement once before recording.
5. Keep the browser tab active while recording.
