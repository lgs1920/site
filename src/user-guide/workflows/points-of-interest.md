
## When To Use POIs

Create or edit POIs when a place needs to be visible or usable in the story. Typical POIs include start points, end points, landmarks, viewpoints, service stops, hazards, and places that should become camera targets.

## Edit A POI

For each important POI, check:

1. Title and description.
2. Parent journey or track.
3. Category and visual treatment.
4. Latitude and longitude.
5. Height or simulated height when the marker needs vertical context.
6. Visibility and expanded state.
7. Camera distance when the POI is used as a focus target.

## Use POIs With Camera

A POI can be used as a focus target. This is useful when you want the camera to arrive on a specific location before starting orbit, panorama, screenshot, or video recording.

Before exporting, focus each key POI once and check that the map framing still supports the story.
