The site search covers the guide, the FAQ, and the project history. Its header button appears after the local search index has finished loading.

## Search

1. Select the magnifying-glass button, or press `Ctrl` + `K` (`Cmd` + `K` on macOS). You can also press `/` when you are not typing in another field.
2. Enter one or more terms in the search field.
3. Review the results, which show the page title, its category, and an excerpt.
4. Select a result to open the matching page.

Matching terms are highlighted in the title and excerpt so they can be found quickly. Results are limited to the current language.
