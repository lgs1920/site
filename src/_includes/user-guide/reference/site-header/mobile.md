## Mobile Header

| Element | Icon or marker | Type | What it does | Visibility and notes |
| --- | --- | --- | --- | --- |
| LGS1920 logo | Compact logo | Link | Returns to the site home page. | Always available. |
| Open Studio | <span class="guide-icon-chip"><wa-icon name="clapperboard-play" variant="regular"></wa-icon></span> | External link | Opens LGS1920 Studio. | Kept as a direct shortcut. |
| Search | <span class="guide-icon-chip"><wa-icon name="magnifying-glass" variant="regular"></wa-icon></span> | Button | Opens the site search dialog. | Available once the search index is ready. |
| Language | Current locale flag | Menu button | Changes the site language. | Shown when another locale is available. |
| Brand and season | Color swatches | Menu button | Changes the brand color and seasonal theme. | The two swatches show the active choices. |
| Color mode | <span class="guide-icon-chip"><wa-icon name="sun-bright" variant="regular"></wa-icon></span> / <span class="guide-icon-chip"><wa-icon name="moon-stars" variant="regular"></wa-icon></span> / <span class="guide-icon-chip"><wa-icon name="desktop" variant="regular"></wa-icon></span> | Menu button | Chooses light, dark, or system color mode. | The icon reflects the active mode. |
| Site navigation | <span class="guide-icon-chip"><wa-icon name="bars" variant="regular"></wa-icon></span> | Toggle button | Opens or closes the main site navigation. | This control is displayed in the mobile header. |

The User guide, GitHub, and Contact buttons are hidden from the mobile header to keep it compact. Their links remain available through the main navigation.
