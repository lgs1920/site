## Header Mobile

| Élément | Icône ou repère | Type | Ce qu'il fait | Visibilité et notes |
| --- | --- | --- | --- | --- |
| Logo LGS1920 | Logo compact | Lien | Retourne à l'accueil du site. | Toujours disponible. |
| Open Studio | <span class="guide-icon-chip"><wa-icon name="clapperboard-play" variant="regular"></wa-icon></span> | Lien externe | Ouvre LGS1920 Studio. | Conservé comme raccourci direct. |
| Recherche | <span class="guide-icon-chip"><wa-icon name="magnifying-glass" variant="regular"></wa-icon></span> | Bouton | Ouvre le dialog de recherche du site. | Disponible une fois l'index de recherche prêt. |
| Langue | Drapeau de la langue courante | Bouton de menu | Change la langue du site. | Affiché lorsqu'une autre langue est disponible. |
| Marque et saison | Nuanciers | Bouton de menu | Change la couleur de marque et le thème saisonnier. | Les deux nuanciers montrent les choix actifs. |
| Mode de couleur | <span class="guide-icon-chip"><wa-icon name="sun-bright" variant="regular"></wa-icon></span> / <span class="guide-icon-chip"><wa-icon name="moon-stars" variant="regular"></wa-icon></span> / <span class="guide-icon-chip"><wa-icon name="desktop" variant="regular"></wa-icon></span> | Bouton de menu | Choisit le mode clair, sombre ou système. | L'icône reflète le mode actif. |
| Navigation du site | <span class="guide-icon-chip"><wa-icon name="bars" variant="regular"></wa-icon></span> | Bouton toggle | Ouvre ou ferme la navigation principale du site. | Ce contrôle est affiché dans l'en-tête mobile. |

Les boutons User guide, GitHub et Contact sont masqués dans l'en-tête mobile pour le garder compact. Leurs liens restent accessibles depuis la navigation principale.
