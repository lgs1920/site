La recherche du site couvre le guide, la FAQ et l'historique du projet. Son bouton dans l'en-tête apparaît une fois l'index de recherche local chargé.

## Recherche

1. Sélectionnez le bouton avec la loupe, ou appuyez sur `Ctrl` + `K` (`Cmd` + `K` sur macOS). Vous pouvez aussi appuyer sur `/` lorsque vous n'écrivez pas dans un autre champ.
2. Saisissez un ou plusieurs termes dans le champ de recherche.
3. Consultez les résultats, qui affichent le titre de la page, sa catégorie et un extrait.
4. Sélectionnez un résultat pour ouvrir la page correspondante.

Les termes recherchés sont surlignés dans le titre et l'extrait pour être repérés rapidement. Les résultats sont limités à la langue courante.
