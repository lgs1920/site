Cette page suit le flux de l'application. Elle part du bouton cliqué, montre ensuite le drawer ou le dialog qu'il ouvre, puis pointe de nouveau vers l'endroit précédent.

## Comment Le Lire

1. Commencez par la section des boutons de la scène principale pour voir ce qui s'ouvre depuis chaque bouton.
2. Suivez le lien du bouton vers la page du drawer ou du dialog.
3. Lisez d'abord la vue d'ensemble en haut de cette page.
4. Utilisez le tableau de contrôles pour voir les boutons, switches, tabs et champs de la surface.
5. Utilisez le lien de retour pour revenir à l'endroit d'où vous venez.
6. Utilisez la page Widgets quand vous avez besoin d'un overlay live ou d'un élément d'export.
