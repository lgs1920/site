Les drawers sont des panneaux latéraux persistants. Ils gardent la scène principale visible pendant que l'utilisateur édite une tâche liée.

Chaque drawer a une page dédiée:

| Drawer | Icône | À quoi il sert | Page |
| --- | --- | --- | --- |
| Drawer Information | <span class="guide-icon-chip"><wa-icon name="circle-info" variant="regular"></wa-icon></span> | Explique l'application et les changements récents. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/information/) |
| Drawer Settings | <span class="guide-icon-chip"><wa-icon name="gear" variant="regular"></wa-icon></span> | Contrôle les réglages globaux de l'application. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/settings/) |
| Drawer Layers | <span class="guide-icon-chip"><wa-icon name="layer-group" variant="regular"></wa-icon></span> | Gère les sources carte et terrain. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/layers/) |
| Drawer Journey editor | <span class="guide-icon-chip"><wa-icon name="route" variant="regular"></wa-icon></span> | Édite le parcours actif. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/journey-editor/) |
| Drawer Journey groups | <span class="guide-icon-chip"><wa-icon name="folders" variant="regular"></wa-icon></span> | Organise les parcours en groupes. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/journey-groups/) |
| Drawer POIs | <span class="guide-icon-chip"><wa-icon name="location-dot" variant="regular"></wa-icon></span> | Édite les points d'intérêt. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/pois/) |
| Drawer Widgets editor | <span class="guide-icon-chip"><wa-icon name="box" variant="regular"></wa-icon></span> | Édite en détail le widget sélectionné. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/widgets-editor/) |
| Drawer Widget management | <span class="guide-icon-chip"><wa-icon name="boxes-stacked" variant="regular"></wa-icon></span> | Réordonne les widgets et les déplace entre boards. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/widget-management/) |
| Drawer Flythrough | <span class="guide-icon-chip"><wa-icon name="video-arrow-up-right" variant="regular"></wa-icon></span> | Contrôle le travail de flythrough caméra. | [Ouvrir la page](/fr/user-guide/reference/studio-interface/drawers/flythrough/) |

Utilisez un drawer quand la tâche fait partie du flux d'édition. Utilisez un dialog quand l'utilisateur doit décider, confirmer ou fournir un jeton avant de continuer.
