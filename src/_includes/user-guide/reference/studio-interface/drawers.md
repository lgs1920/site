Drawers are persistent side panels. They keep the main scene visible while the user edits a related task.

Each drawer has a dedicated page:

| Drawer | Icon | What it is for | Page |
| --- | --- | --- | --- |
| Information drawer | <span class="guide-icon-chip"><wa-icon name="circle-info" variant="regular"></wa-icon></span> | Explains the app and recent changes. | [Open page](/user-guide/reference/studio-interface/drawers/information/) |
| Settings drawer | <span class="guide-icon-chip"><wa-icon name="gear" variant="regular"></wa-icon></span> | Controls global application settings. | [Open page](/user-guide/reference/studio-interface/drawers/settings/) |
| Layers drawer | <span class="guide-icon-chip"><wa-icon name="layer-group" variant="regular"></wa-icon></span> | Manages map and terrain sources. | [Open page](/user-guide/reference/studio-interface/drawers/layers/) |
| Journey editor drawer | <span class="guide-icon-chip"><wa-icon name="route" variant="regular"></wa-icon></span> | Edits the active journey. | [Open page](/user-guide/reference/studio-interface/drawers/journey-editor/) |
| Journey groups drawer | <span class="guide-icon-chip"><wa-icon name="folders" variant="regular"></wa-icon></span> | Organizes journeys into groups. | [Open page](/user-guide/reference/studio-interface/drawers/journey-groups/) |
| POIs drawer | <span class="guide-icon-chip"><wa-icon name="location-dot" variant="regular"></wa-icon></span> | Edits points of interest. | [Open page](/user-guide/reference/studio-interface/drawers/pois/) |
| Widgets editor drawer | <span class="guide-icon-chip"><wa-icon name="box" variant="regular"></wa-icon></span> | Edits the selected widget in detail. | [Open page](/user-guide/reference/studio-interface/drawers/widgets-editor/) |
| Widget management drawer | <span class="guide-icon-chip"><wa-icon name="boxes-stacked" variant="regular"></wa-icon></span> | Reorders widgets and moves them between boards. | [Open page](/user-guide/reference/studio-interface/drawers/widget-management/) |
| Flythrough drawer | <span class="guide-icon-chip"><wa-icon name="video-arrow-up-right" variant="regular"></wa-icon></span> | Controls camera flythrough work. | [Open page](/user-guide/reference/studio-interface/drawers/flythrough/) |

Use a drawer when the task is part of the editing flow. Use a dialog when the user must decide, confirm, or provide a token before continuing.
