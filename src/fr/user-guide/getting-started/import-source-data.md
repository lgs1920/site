## Fichiers Pris En Charge

Commencez depuis le bouton d'import ou le prompt de première session. Studio prend en charge les sources GeoJSON, GPX et KML. Le contenu importé devient modifiable dans la session courante.

## Checklist D'import

Après l'import, vérifiez que:

1. Le parcours apparaît dans la liste.
2. Les traces sont visibles sur la carte.
3. Le titre, la description, l'activité, le lieu et le pays détectés sont exploitables.
4. Le focus sur le parcours ne déplace pas la caméra à un endroit inattendu.
5. Le parcours importé a bien les positions de départ et d'arrivée attendues.

## Après L'import

Continuez avec [Modifier les parcours et traces](/fr/user-guide/workflows/journeys-and-tracks/) pour affiner la présentation, ou allez directement à [Utiliser les POI](/fr/user-guide/workflows/points-of-interest/) si le style de trace est déjà correct.
