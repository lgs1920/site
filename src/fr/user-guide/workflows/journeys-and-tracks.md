## Parcours Vs Trace

Un parcours est le conteneur global. Il regroupe les métadonnées, les traces, les POI, l'état caméra, les réglages de rotation, de panorama et d'export.

Une trace est la géométrie visible du parcours. Les contrôles de trace servent à la couleur, l'épaisseur, la visibilité et la relecture des données.

## Ouvrir Track Editor

Il n'y a pas de bouton Track Editor indépendant au premier niveau. Le flux part du bouton `Journey` dans la scène principale.

1. Ouvrez le bouton `Journey` dans la barre principale.
2. Choisissez l'action d'édition.
3. Le [drawer Journey editor](/fr/user-guide/reference/studio-interface/drawers/journey-editor/) s'ouvre.
4. Sélectionnez la trace à modifier dans ce drawer.
5. Ajustez la visibilité, le style et les champs associés.
6. Fermez le drawer quand la scène correspond au rendu voulu.

## Modifier Le Parcours

1. Sélectionnez le parcours actif.
2. Renommez-le avec un titre clair.
3. Vérifiez la description, l'activité, le lieu, le pays et la visibilité.
4. Activez ou désactivez la visibilité des POI au niveau parcours.
5. Focalisez le parcours pour vérifier le cadrage caméra.

## Modifier Les Traces

1. Sélectionnez la trace dans le parcours actif.
2. Ajustez la couleur et l'épaisseur.
3. Activez ou désactivez la visibilité.
4. Vérifiez les points de trace si le chemin paraît incorrect.
5. Focalisez la trace pour valider son emprise.
