
## Sorties De Rapport

Utilisez les rapports quand la sortie doit être un document complet plutôt qu'une simple image ou vidéo. Studio peut exporter le parcours actif en PDF ou en rapport HTML empaqueté dans une archive ZIP.

## Contenu Du Rapport

Un rapport peut inclure les métadonnées, la description, les statistiques, les dates, le profil altimétrique, les tableaux de POI, les coordonnées et les données d'altitude.

## Checklist Export

1. Sélectionnez le parcours actif.
2. Vérifiez le titre, la description, l'activité, le lieu, les dates et la visibilité.
3. Vérifiez distance, dénivelé, durée, vitesse, pente et profil altimétrique.
4. Générez le PDF ou le HTML ZIP.
