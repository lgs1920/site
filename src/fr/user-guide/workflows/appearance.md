
## Ouvrir Settings

Depuis la scène Studio:

1. Cliquez sur le bouton `Settings`.
2. Le [drawer Settings](/fr/user-guide/reference/studio-interface/drawers/settings/) s'ouvre.
3. Ouvrez l'onglet `User Interface`.

## Changer Le Thème

1. Choisissez `Light`, `Dark` ou `System`.
2. Vérifiez la scène, les drawers et les dialogs après le changement.
3. Gardez le mode qui rend les lignes, POI et contrôles les plus lisibles.

## Changer La Couleur

1. Choisissez la couleur de marque.
2. Choisissez la palette saisonnière si elle est disponible.
3. Vérifiez les boutons, liens, états sélectionnés et puces de tableau.
4. Évitez les combinaisons qui dégradent le contraste.
