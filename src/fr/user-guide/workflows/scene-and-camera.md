
## Choisir Le Mode

Utilisez le mode de scène qui sert le mieux la sortie:

- 2D pour la lisibilité plane.
- 3D pour le relief, la profondeur et plus de contexte spatial.

## Focaliser La Cible

Le focus déplace la caméra sur l'objet ou la coordonnée sélectionnée. Utilisez-le avant le cadrage fin pour partir d'une base stable.

1. Sélectionnez le parcours, la trace, le POI ou la coordonnée.
2. Focalisez la cible.
3. Ajustez la distance, le heading, le pitch ou la hauteur.
4. Vérifiez les labels, marqueurs et widgets après stabilisation.

## Contrôles De Mouvement

Orbit fait tourner la caméra autour d'une cible. Panorama crée un point de vue mobile avec hauteur, pitch, vitesse et direction réglables.
