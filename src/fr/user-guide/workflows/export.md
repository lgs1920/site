## Choisir La Sortie

| Besoin | Utiliser |
| --- | --- |
| Une image composée | Snapshot |
| Un mouvement de caméra ou une scène animée | Video |
| Une documentation complète du parcours | Journey report |

## Capture Et Vidéo

1. Préparez les couches, la visibilité, les POI, les widgets et la caméra.
2. Vérifiez la zone de capture et le ratio.
3. Lancez l'action snapshot ou video.
4. Relisez la sortie générée avant de modifier la scène.

Flux détaillé: [Captures et vidéo](/fr/user-guide/workflows/snapshots-and-video/).

## Rapport

1. Sélectionnez le parcours actif.
2. Vérifiez le titre, la description, les dates, les statistiques, les POI et le style.
3. Générez le rapport PDF ou HTML ZIP.
4. Ouvrez le fichier exporté et relisez cartes et tableaux.

Flux détaillé: [Rapports de parcours](/fr/user-guide/workflows/journey-reports/).
