
## Tableau Des Actions

| Action | Exemple d'icône | Résultat |
| --- | --- | --- |
| Lancer Studio | <wa-icon variant="regular" name="clapperboard-play"></wa-icon> | Ouvre l'application d'édition hébergée. |
| Importer | <wa-icon variant="regular" name="file-import"></wa-icon> | Charge des fichiers source GeoJSON, GPX ou KML. |
| Focaliser | <wa-icon variant="regular" name="bullseye"></wa-icon> | Déplace la caméra vers l'objet ou la coordonnée sélectionnée. |
| Rotation | <wa-icon variant="regular" name="arrows-rotate"></wa-icon> | Démarre ou ajuste l'orbite autour de la cible. |
| Panorama | <wa-icon variant="regular" name="panorama"></wa-icon> | Démarre ou ajuste le mouvement de panorama. |
| Éditer | <wa-icon variant="regular" name="pen-to-square"></wa-icon> | Ouvre les réglages de l'objet ou les contrôles d'édition inline. |
| Basculer la visibilité | <wa-icon variant="regular" name="eye"></wa-icon> | Affiche ou masque un objet ou un overlay. |
| Géocoder | <wa-icon variant="regular" name="location-crosshairs"></wa-icon> | Recherche un lieu ou un contexte de coordonnées pour positionner la carte. |
| Exporter un rapport | <wa-icon variant="regular" name="file-pdf"></wa-icon> | Génère un rapport PDF ou un rapport HTML ZIP pour le parcours actif. |
| Capturer | <wa-icon variant="regular" name="camera"></wa-icon> | Crée une image fixe depuis la composition courante. |
| Enregistrer | <wa-icon variant="regular" name="video"></wa-icon> | Enregistre une vidéo avec la scène et les overlays actifs. |
| Exporter | <wa-icon variant="regular" name="download"></wa-icon> | Télécharge le média généré ou une sortie de données supportée. |

## Vérifications

1. Confirmez le parcours, la trace, le POI ou le widget sélectionné.
2. Vérifiez si l'action modifie la visibilité, la position ou l'état enregistré.
3. Re-focalisez la caméra après les changements d'objets importants.
4. Relisez métadonnées, POI, statistiques, coordonnées et altitudes avant de générer un rapport.
5. Relisez la scène avant une capture ou un enregistrement.
