## Découvrir Studio

Studio permet d’explorer une sortie GPS dans le navigateur, d’en modifier la présentation sur la carte et d’en tirer des images, une vidéo ou un rapport. Un **parcours** (*Journey*) rassemble la sortie entière. Ses **traces** en dessinent les lignes sur la carte. [Comprendre les parcours et les traces](/fr/user-guide/workflows/journeys-and-tracks/).

<span id="session-type"></span>

## Créer ma première capture

Prenez le fichier GPS d’une sortie que vous connaissez. Le guide rapide vous accompagne pour l’importer, retrouver la trace, cadrer la carte et enregistrer une image.

**[Suivre le guide rapide](/fr/user-guide/getting-started/first-steps/)**
