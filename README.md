# LGS1920 Site

Static 11ty marketing site for `LGS1920 Studio`, using self-hosted Web Awesome components.

## Prerequisites

- Bun

## Development

```bash
bun install
bun run dev
```

The Eleventy dev server runs on `http://localhost:8080`.

## Build

```bash
bun run build
```

The generated site is written to `_site/`.
